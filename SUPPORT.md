# 💬 Support

## 🐛 Bugs

Open a bug report using the issue template. Include the integration version,
Home Assistant version, FlexGet version, sanitized diagnostics, expected
behavior, and relevant logs.

Never post an API token. Check pasted URLs, headers, logs, screenshots, and
diagnostics before submitting them.

## 💡 Feature requests

Use the feature-request template and explain the user problem rather than only
the preferred implementation. Features that execute tasks or manage daemons
need an explicit security and confirmation design.

## 🧭 Setup help

Manual host/port/token configuration is the standard setup. Optional Avahi
discovery is documented in `README.md` as an advanced convenience. If discovery
does not work, manual setup provides the same monitoring features.

This is a community integration and support is provided on a best-effort basis.
